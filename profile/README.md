This organization hosts the package manifests. The app itself is developed in [remcostoeten/skriuw](https://github.com/remcostoeten/skriuw).

```sh
brew install --cask skriuw/tap/skriuw                              # macOS
scoop bucket add skriuw https://github.com/skriuw/scoop-bucket     # Windows
scoop install skriuw
```
